# HomeRelay

写真と声で30秒以内に記録し、家族・親族が5秒で理解できる、家族・親族・訪問ヘルパー向けの申し送りWebアプリです。

## 起動

Node.js 22以降で、リポジトリ直下から実行します。

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 緊急MVPで動作する範囲

- 合成データだけを使うローカルデモ
- アプリ内での写真撮影、撮り直し、採用
- 音声録音から合成AI下書きへの遷移と、共有前の編集・確認
- `これでOK`の後、`次の人へ`を押したときだけ共有
- 同じPCの別タブにある家族画面への即時表示
- 必要品の`購入します`、`購入しました`への状態変更

別タブ共有はローカル合成デモ用です。スマートフォンとPCなど、別端末間のクラウド同期を実装済みとは扱いません。

## 60秒デモ

1. 家族用タブで [http://localhost:3000](http://localhost:3000) を先に開きます。
2. 同じPCの別タブで [http://localhost:3000/record](http://localhost:3000/record) を開きます。
3. `写真を撮る`から合成デモ用の食事を撮影し、写真を採用します。
4. `声で話す`を押して短く話し、録音を止めます。
5. 表示された合成AI下書きを必要に応じて編集します。
6. `これでOK`を押します。この時点ではまだ家族タブへ共有されません。
7. `次の人へ`を押します。
8. 家族用タブへ戻り、申し送りが即時表示されたことを確認します。
9. 必要品の`購入します`を押します。
10. 続けて`購入しました`を押します。

## 外部サービスの状態

資格情報がない状態では、OpenAI、Supabase、Qdrant、Neo4j、Datadogなどの外部サービスは未接続です。画面に表示される合成下書きや関連情報を、ライブ連携の成功結果として扱わないでください。

SupabaseによるAuth、Storage、Database、Realtime、RLSと、追加スポンサー向け統合は、この緊急MVPでは作業を中止しており未完成です。そのため、クラウド保存、別端末へのRealtime配信、ライブQdrant検索、Neo4jグラフ機能は動作保証の対象外です。

## 安全上の境界

- HomeRelay専用の独立プロジェクトです。
- CareRelayにはアクセス、参照、変更、コピー、連携していません。
- 実在する利用者・家族・ヘルパーの情報を入力せず、合成データだけを使用してください。
- 訪問看護師向け機能や、事業者の公式サービス記録は扱いません。
